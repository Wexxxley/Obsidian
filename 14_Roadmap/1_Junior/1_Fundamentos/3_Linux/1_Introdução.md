### 1. Onde o Linux Domina

Por ser versátil e de código aberto, o Linux é empregado em uma gama massiva de ambientes, muito além do computador pessoal.

**1.1. Servidores**: Este é o território principal do Linux. A grande maioria dos servidores que rodam a internet utiliza Linux. 

**1.2. Supercomputadores (High-Performance Computing - HPC)**: Aqui o domínio é absoluto. O ranking dos 500 supercomputadores mais rápidos do mundo, 100% deles rodam Linux.

**1.3. Sistemas Embarcados (Embedded Systems)**

- **Android:** Quando você usa um celular Android, o sistema operacional que você vê é o Android, mas o núcleo (kernel) desse sistema é o Linux.
    
- **Smart TVs:** Muitas TVs rodam sistemas baseados em Linux, como o **WebOS** (da LG).
    
- **Outros:** Roteadores Wi-Fi, mini-computadores e até sistemas automotivos rodam Linux.

### **2. Unix**

Unix é tanto um sistema operacional histórico específico quanto uma filosofia de design que inspirou quase todos os sistemas operacionais modernos, com exceção notável do Windows (que foi criado com uma arquitetura diferente).

Em sua essência, o Unix é um sistema operacional **portátil**, **multitarefa** e **multiusuário**.

- **Multitarefa:** Consegue executar múltiplos programas (processos) ao mesmo tempo.
- **Multiusuário:** Permite que vários usuários acessem o computador e seus recursos simultaneamente, mantendo seus arquivos e processos separados e seguros.
- **Portátil:** Foi um dos primeiros sistemas projetados para não depender de um hardware específico, podendo ser "portado" para diferentes máquinas.

O que realmente define o Unix não é apenas o código, mas sua filosofia de design:
- **Tudo é um arquivo:** No Unix, quase tudo no sistema é tratado como um arquivo, incluindo dispositivos (como seu mouse ou impressora) e até mesmo processos em execução. 
- **Ferramentas pequenas e especializadas:** A filosofia é criar programas pequenos que façam apenas _uma_ coisa, mas que a façam muito bem.
- **Pipes (Canalizações):** Você pode "ligar" essas ferramentas pequenas. A saída de um programa pode se tornar a entrada de outro. Isso permite construir fluxos de trabalho complexos combinando ferramentas simples.    

#### 2.1 "Unix" vs. "Unix-like" vs. "Linux"

- **Unix (Marca Registrada):** O nome "UNIX" (em maiúsculas) é uma marca registrada que pertence a um consórcio chamado "The Open Group". Para um sistema operacional ser chamado oficialmente de "UNIX", ele precisa pagar e ser certificado como compatível com um padrão chamado "Single UNIX Specification" (SUS). O **macOS** da Apple, por exemplo, é um sistema operacional certificado como UNIX.
    
- **Unix (Histórico/Comercial):** Refere-se às versões comerciais e de código fechado originais ou descendentes diretos do código da AT&T, como Solaris, HP-UX e AIX.
    
- **Unix-like:** Esta é a categoria mais ampla. Refere-se a sistemas operacionais que _não_ são certificados ou não usam o código original da AT&T, mas foram **inspirados** pela filosofia Unix e funcionam de maneira muito semelhante.
    
- **Linux:** O Linux se encaixa perfeitamente aqui. Ele é um sistema "Unix-like". Linus Torvalds o criou do zero, sem usar nenhum código Unix original, mas o projetou para se comportar e funcionar exatamente de acordo com a filosofia Unix.

---

O Linux não é um sistema isolado; ele faz parte de uma grande família de sistemas operacionais que seguem o padrão "Unix".
 
- **O Papel do BSD:** Outro sistema importante dessa família é o **BSD**. A licença do BSD é diferente da do Linux e permite que empresas peguem o código-fonte (aberto) e o utilizem para criar produtos de código _fechado_ (proprietário).
    
- **Exemplos de BSD no dia a dia:**
    
    - **Apple (macOS):** O núcleo do macOS (chamado "Darwin") é derivado do BSD. A Apple pegou essa base livre, construiu sua interface gráfica proprietária por cima e fechou o código.
        
    - **Sony (PlayStation):** O sistema operacional do PlayStation 3 e 4 também tem como base o BSD.
        
    - **Microsoft (Windows):** É mencionado que, historicamente, parte da camada de rede do Windows também foi derivada do BSD.
        

### Tópico 3: O Linux no Mundo Corporativo (Microsoft, Google, etc.)

Esta seção foca em desmistificar a ideia de que o Linux é "anti-empresas", mostrando que o oposto é verdade.

- **A Mudança da Microsoft:** O vídeo destaca a ironia da mudança de postura da Microsoft.
    
    - **Antes:** O antigo CEO (Steve Ballmer) chegou a dizer que o "Linux é um câncer".
        
    - **Hoje:** O novo CEO (Satya Nadella) declarou publicamente "Nós amamos o Linux".
        
    - **Prova Concreta:** Atualmente, a Microsoft é uma das principais mantenedoras da Linux Foundation (membro "Platinum") e disponibiliza ferramentas como o Visual Studio Code para Linux, que "funciona lindamente".
        
- **Outras Gigantes:** Quase toda grande empresa de tecnologia usa e contribui para o Linux.
    
    - **Google:** É um usuário massivo de Linux em seus servidores e infraestrutura (além de usá-lo como base para o Android).
        
    - **Empresas que Usam/Contribuem:** IBM, Intel, AMD, Oracle (que tem sua própria distribuição Linux), HP, NASA, Petrobras (em supercomputadores para prospecção de petróleo), entre muitas outras.
