
---
DecimalFormat é uma classe do Java que serve para formatar números. Ele funciona através de uma **string de padrão**, que define como o número deve ser formatado. Os caracteres mais comuns são:

- **`#`:** Representa um dígito **opcional**.
- **`0`:** Representa um dígito **obrigatório**. 
- **`.`:** Separador decimal.
- **`,`:** Define o separador de grupo.
- **Moeda** Serve para representar o símbolo de moeda (`R$`, `$`, `€`, etc.).
