### **1. O que é Interface?**

A interface não é apenas a "telinha" que você vê. <mark style="background: #ADCCFFA6;">A interface compreende toda a porção do sistema com a qual o usuário mantém contato (físico ou conceitual) durante a interação</mark>. É o único meio de contato entre o usuário e o sistema.    

- **Contato Físico:**
    1. **Dispositivos de entrada:** Usuário participa ativamente (ex: teclado, mouse).
    2. **Dispositivos de saída:** Onde o usuário participa passivamente, recebendo informações (ex: monitor, caixas de som).
        
- **Contato Conceitual:** É como o usuário entende o que percebe e como ele planeja seus próximos passos na interação. Basicamente, é o "modelo mental" que o usuário cria de como o software funciona.
    

Fatores de Influência:

A interface não existe no vácuo. Ela é influenciada por:

- **Contexto de uso:** Ex: Uma resposta sonora pode ser inútil em um ambiente barulhento6.
    
- **Características do usuário:** Fatores físicos (ex: daltonismo) e cognitivos/culturais (ex: nível de letramento) definem se uma interface é apropriada ou não 7.
    

### 2. O que é Interação?

O material define interação através de quatro pilares principais 8:

1. **Comunicação**
    
2. **Troca**
    
3. **Influência**
    
4. **Manipulação**
