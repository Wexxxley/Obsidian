
#Concluded 


---
- **Git** é a _ferramenta_ de linha de comando que você instala no seu computador para rastrear mudanças.
    
- **GitHub** é um _website_ onde você pode enviar seus projetos Git. Ele atua como o **repositório remoto** centralizado, permitindo que você armazene seu código online e colabore com outras pessoas.

**Começando no GitHub:**
1. **Registro:** O primeiro passo é criar uma conta no site do GitHub.
2. **Repositório:** Um repositório é apenas um nome para um "projeto". É onde você armazena todos os arquivos, pastas e histórico do seu projeto.
3. **Colaboradores:** Você pode convidar outras pessoas (colaboradores) para trabalhar no seu projeto. 
4. **O Arquivo `README.md`:**
    - O `README.md` é a introdução do seu projeto. É a primeira coisa que as pessoas veem.
    - É essencial ter um bom README para que outros possam entender sobre o que é seu projeto e como usá-lo2.
