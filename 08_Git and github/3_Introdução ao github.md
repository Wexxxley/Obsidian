- **Git** é a _ferramenta_ de linha de comando que você instala no seu computador para rastrear mudanças.
    
- **GitHub** é um _website_ onde você pode enviar seus projetos Git. Ele atua como o **repositório remoto** centralizado, permitindo que você armazene seu código online e colabore com outras pessoas.

**Começando no GitHub:**
1. **Registro:** O primeiro passo é criar uma conta no site do GitHub.
2. **Repositório (Repo):** Um repositório é apenas um nome para um "projeto"17. É onde você armazena todos os arquivos, pastas e histórico do seu projeto18.
    
3. **Repositórios Públicos vs. Privados:**
    
    - **Público:** Qualquer pessoa na internet pode ver seu repositório19. É o padrão para projetos de código aberto (open-source)20.
        
    - **Privado:** Só você e as pessoas que você convidar podem ver e acessar o repositório21.
        
4. **Colaboradores:** Você pode convidar outras pessoas (colaboradores) para trabalhar no seu projeto22. Você pode fazer isso na aba "Settings" (Configurações) > "Manage access" (Gerenciar acesso) do seu repositório23.
    
5. **O Arquivo `README.md`:**
    
    - Este é um arquivo crucial. O `.md` significa **Markdown** (uma linguagem simples para formatar texto)24.
        
    - O `README.md` é a "capa" ou a introdução do seu projeto25. É a primeira coisa que as pessoas veem.
        
    - É essencial ter um bom README para que outros possam entender sobre o que é seu projeto e como usá-lo26262626.
