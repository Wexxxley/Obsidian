### **1. O que é Git?**

Git é o **Sistema de Controle de Versão (VCS)** de código aberto mais popular que existe. E foi criado por Linus Torvalds. Seu objetivo principal é<mark style="background: #ADCCFFA6;"> rastrear mudanças no código-fonte e ajudar os programadores a coordenar o trabalho em equipe.</mark>

- Git é um **VCS Distribuído**. Significa que você não tem apenas uma cópia do código. Você tem:
	1. Repositório local.
	2. Repositório remoto.

---
### 2. Instalando o Git

- Linux (Debian/Ubuntu):
    `sudo apt install git-all`
    
- Windows:
    Você deve baixar o instalador. Durante a instalação, é importante selecionar a opção Git Bash, que fornecerá um terminal para usar os comandos.

---
### **3. Comandos Básicos do terminal**

- `ls`: Lista os arquivos e pastas no seu diretório atual. (No Windows, `dir`).
    ![](../attachments/Pasted%20image%2020251111152211.png)
- `pwd`: (Print Working Directory) Mostra o caminho completo da pasta onde você está agora28.
    ![](../attachments/Pasted%20image%2020251111152138.png)
- `cd`: (Change Directory) Navega entre as pastas.
    - `cd NamePasta
    - `cd ..` (para voltar um nível).
        
- `rm`: Deleta arquivos.Para deletar um diretório, você precisa usar a flag `-r` (ex: `rm -r nome-da-pasta`).
    ![](../attachments/Pasted%20image%2020251111152728.png)
