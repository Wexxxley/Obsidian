### 1. Preparação do Ambiente Base

Como você não possui os arquivos necessários, a primeira etapa é configurar a infraestrutura de virtualização. As simulações não devem ser feitas na sua rede real, mas sim em um laboratório virtual.

- **Software de Virtualização:** Você precisará baixar e instalar um hipervisor, que é um programa responsável por criar computadores simulados dentro do seu sistema físico. As opções recomendadas são o VirtualBox ou o VMware Workstation Pro. O VirtualBox é uma opção gratuita e amplamente utilizada.
    
- **Sistemas Operacionais (Máquinas Virtuais):** O requisito do projeto é possuir duas ou mais máquinas virtuais rodando sistemas baseados em Linux.
    
    - Para a máquina do atacante, é altamente recomendado baixar a imagem do Kali Linux, pois este sistema operacional já contém ferramentas de segurança pré-instaladas.
        
    - Para a máquina que atuará como vítima ou servidor, você pode baixar uma distribuição padrão, como o Ubuntu ou o Debian.
        
- **Configuração de Rede Isolada:** Após criar as duas máquinas virtuais no software de virtualização, você deve configurar as propriedades de rede de ambas para o modo "Rede Interna". Isso garantirá que elas se comuniquem apenas entre si e fiquem sem acesso à internet externa, prevenindo impactos em sistemas reais.
    

### 2. Execução do Módulo 1: ARP Spoofing e Man-in-the-Middle (MitM)

Este ataque consiste em falsificar as tabelas do Protocolo de Resolução de Endereços (ARP). Na prática, o atacante engana a máquina da vítima para que ela envie o tráfego de rede para ele, em vez de enviar para o roteador legítimo.

- **Ferramentas necessárias:** Bettercap e Wireshark (ambas nativas no Kali Linux).
    
- **Passo 1:** Certifique-se de que a rede virtual interna entre as máquinas está funcional e que elas conseguem se comunicar.
    
- **Passo 2:** Utilize comandos de terminal (como `ip a` ou `ifconfig`) para identificar os endereços IP (identificação lógica) e MAC (identificação física do hardware) da máquina da vítima e do gateway (o roteador da rede virtual).
    
- **Passo 3:** Na máquina do atacante, inicie o software Bettercap especificando o endereço IP da máquina vítima como o alvo do ataque de falsificação ARP.
    
- **Passo 4:** Abra o software Wireshark na máquina do atacante. Ele atuará como um farejador de pacotes, capturando todo o tráfego de rede que agora está sendo desviado.
    
- **Passo 5:** Analise os dados interceptados no Wireshark, demonstrando como é possível visualizar informações sensíveis, como sessões e senhas não criptografadas, trafegando pela rede.
    
- **Passo 6 (Defesa):** Para concluir o módulo, você deve apresentar as mitigações, explicando que a implementação de protocolos criptografados (como o HTTPS), o uso de Redes Privadas Virtuais (VPN) ou a configuração de tabelas ARP estáticas invalidam a interceptação legível dos dados.
    

### 3. Execução do Módulo 4: IP Spoofing

Este módulo demonstra o envio de pacotes de dados utilizando endereços de IP de origem falsificados. É uma técnica frequentemente utilizada para ocultar a identidade do atacante em ataques de Negação de Serviço (DoS), que visam sobrecarregar um sistema.

- **Ferramenta necessária:** hping3 (nativa no Kali Linux).
    
- **Passo 1:** Utilize a segunda máquina virtual (a vítima) e configure-a para atuar como um servidor simulado, pronto para receber o tráfego de rede.
    
- **Passo 2:** Na máquina do atacante, execute o comando hping3 no terminal. Você deve utilizar os parâmetros da ferramenta que permitem definir um endereço IP de origem aleatório ou específico, mascarando o seu IP real.
    
- **Passo 3:** Na máquina servidor, utilize uma ferramenta de monitoramento de rede (como o próprio Wireshark ou tcpdump) para monitorar a chegada dos pacotes.
    
- **Passo 4:** Inspecione os cabeçalhos dos pacotes de dados recebidos no servidor. O objetivo é confirmar que o sistema da vítima registra os pacotes como se viessem do endereço IP falso configurado no hping3, provando a eficácia da falsificação.
    
- **Passo 5 (Defesa):** Apresente as medidas de segurança adequadas. Explique como a configuração de Firewalls, Sistemas de Detecção e Prevenção de Intrusão (IDS/IPS) e filtros de verificação de rota (uRPF) conseguem detectar pacotes com origens forjadas e bloqueá-los.
