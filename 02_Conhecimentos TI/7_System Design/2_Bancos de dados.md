Banco de dados são sistemas utilizados para armazenar, administrar e recuperar dados. São eficientes, robustos e oferecerem escalabilidade.

### 1. Bancos de Dados SQL 

Os dados são organizados em tabelas e possuem formato estruturado.
- **Schema-on-Write:** O banco verifica ativamente se o formato recebido pelo cliente coincide com o formato tipado da coluna na tabela.
- **ACID:** Garantem a integridade das operações através das propriedades de **Atomicidade, Consistência, Isolamento e Durabilidade.**
- Indicados para domínios que exigem alta confiabilidade de dados e buscas complexas, como instituições financeiras e marketplaces.
