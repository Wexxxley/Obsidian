### 2. O Próximo Nível: Agentes Baseados em Objetivos

A grande introdução desta aula é o **Agente Baseado em Objetivo**6.

- **A Diferença Chave:** Este agente não se baseia mais em "Regras condição-ação" pré-programadas para cada situação. Em vez disso, ele tem **Objetivos**7.
    
- **Como Funciona:** Além de saber como o mundo está (como o agente de modelo), ele também se pergunta: "**Como ficará o mundo se for executada a ação A?**"8.
    
- **O Processo:** Em vez de apenas reagir, este agente **planeja**. Ele considera sequências de ações futuras para encontrar uma que o leve ao seu estado de objetivo. Isso levanta três questões centrais:
    
    1. Como definir um problema? 9
        
    2. Como definir um objetivo? 10
        
    3. Como construir algoritmos que alcancem os objetivos? 11
        

Este tipo de agente é o foco da **Resolução de Problemas**12.

### 3. A Tarefa Principal: Formulação de Problemas

O primeiro passo para um agente de resolução de problemas é **Formular o Problema**13131313. Esta aula define formalmente o que é um "problema".

Um problema é composto por **cinco componentes**:

1. **O Estado Inicial:** Onde o agente começa14141414141414141414141414141414141414141414141414.
    
2. **Uma Descrição das Ações:** O que o agente _pode_ fazer em um determinado estado, $s$. (definido como $ACOES(s)[cite_start]$)15151515151515151515151515151515.
    
3. **Um Modelo de Transição:** O que uma ação $a$ faz no estado $s$. (definido como $RESULTADO(s, a)[cite_start]$)161616161616161616.
    
4. **O Teste de Objetivo:** Uma forma de determinar se um estado específico é o estado-objetivo17171717.
    
5. **Um Custo de Caminho:** Uma função que atribui um custo a uma sequência de ações (caminho)18.
    

### 4. Exemplo e Atividade: O Mapa da Romênia

Para solidificar esses conceitos, a aula usa um exemplo clássico: o **Mapa Rodoviário da Romênia** 19.

Os slides propõem uma atividade onde os alunos devem aplicar os 5 componentes da formulação do problema a este mapa 20. Por exemplo:

- **Estado Inicial:** "Em Arad"21.
    
- **Ações:** "Ir para Sibiu", "Ir para Zerind", "Ir para Timisoara".
    
- **Modelo de Transição:** `RESULTADO("Em Arad", "Ir para Sibiu")` = "Em Sibiu".
    
- **Teste de Objetivo:** "Estamos em Bucharest?"22.
    
- **Custo de Caminho:** A soma das distâncias em km entre as cidades (ex: o custo de Arad $\rightarrow$ Sibiu é 140)23.
    

### 5. Guia de Implementação

Por fim, os slides dão um roteiro de como implementar essa formulação em código24:

- **Classe Estado:** Deve conter o `nome do estado` e uma `lista das transições` que saem dele 25.
    
- **Classe Transição:** Deve conter o `estado destino` e o `custo da aresta` (o custo para chegar lá) 26.
    
- **Classe Mapa:** Deve conter um `conjunto de estados`27.
    

Em resumo, esta aula faz a transição de agentes que **reagem** para agentes que **planejam**, estabelecendo o fundamento formal (a formulação do problema) necessário para que um agente possa encontrar uma sequência de ações para atingir um objetivo.
