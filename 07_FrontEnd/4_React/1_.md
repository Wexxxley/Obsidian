#### 1. Arquitetura SPA vs. Server-Side Rendering

**Renderização Tradicional:** Anteriormente, websites eram renderizados no servidor. Cada interação do usuário (como uma navegação) resultava em uma nova requisição ao servidor, que retornava um documento HTML completo, CSS e JavaScript, causando um reload da página .
    
**Single-Page Applications (SPA):** Frameworks modernos transferiram o foco do servidor para o cliente. Em uma SPA, o servidor entrega um arquivo HTML mínimo e um pacote JavaScript.
- O navegador executa esse JavaScript, que é responsável por renderizar toda a aplicação e gerenciar interações. Transições de página subsequentes não requerem novas requisições de arquivos ao servidor; o JavaScript carregado inicialmente renderiza dinamicamente o novo conteúdo .
        
- O React atua como a biblioteca para arquitetar essa aplicação baseada em JavaScript, utilizando o conceito de **Componentes** para encapsular aspectos visuais e funcionais.

#### 2. Pré-requisitos de Tooling: Node e NPM (Páginas 14 a 15)

Para o desenvolvimento moderno em React, o ambiente requer:

- **Node.js e NPM:** Necessários para gerenciar bibliotecas e dependências (pacotes Node) que o projeto utilizará. O NPM (Node Package Manager) permite a instalação via linha de comando.
    

#### 3. Inicialização do Projeto com Vite (Páginas 16 a 17)

O livro adota o **Vite** como ferramenta de build, substituindo configurações manuais complexas. O Vite consiste em dois componentes principais:

1. **Servidor de Desenvolvimento:** Permite executar a aplicação localmente.
    
2. **Bundler:** Gera arquivos otimizados para o ambiente de produção.
    

**Comando de criação:** O projeto é inicializado via linha de comando, utilizando o template React:

Bash

```
npm create vite@latest hacker-stories -- --template react
```

.

Após a criação, as dependências listadas no `package.json` são instaladas via `npm install` e o servidor é iniciado com `npm run dev` .

#### 4. Estrutura de Arquivos e Scripts (Páginas 18 a 21)

Ao abrir o projeto, a estrutura de diretórios revela a arquitetura técnica da aplicação:

- **`package.json`:** Manifesto do projeto que lista dependências e scripts de configuração.
    
- **`vite.config.js`:** Arquivo de configuração do Vite, onde plugins (como o plugin do React) são definidos.
    
- **`index.html`:** O ponto de entrada no navegador. Ele contém um elemento `div` (geralmente com `id="root"`) e uma tag `<script>` que aponta para o código fonte (`src/main.jsx`) . O React injetará a aplicação dentro deste `div`.
    
- **`src/`:** Diretório contendo o código-fonte da aplicação.
    
    - **`src/main.jsx`:** O ponto de entrada JavaScript (entry point).
        
    - **`src/App.jsx`:** Onde o componente raiz da aplicação é implementado.
        

**Scripts NPM (Página 15/20):** Os scripts definidos no `package.json` automatizam tarefas:

- `npm run dev`: Inicia o servidor de desenvolvimento.
    
- `npm run build`: Compila a aplicação para a pasta `dist/`, pronta para produção.
    
- `npm run preview`: Simula o ambiente de produção localmente após o build.
