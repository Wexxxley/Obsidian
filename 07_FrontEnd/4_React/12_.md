### **React Component Composition (Páginas 95-97)**

Até agora, tratamos nossos componentes customizados como tags de fechamento automático (self-closing tags), passando dados exclusivamente através de atributos (props).

JavaScript

```
<InputWithLabel label="Search" ... />
```

No entanto, elementos HTML nativos frequentemente possuem conteúdo interno (inner content):

HTML

```
<label>Search</label>
```

O React permite imitar esse comportamento utilizando a prop especial **`children`**.

#### Refatoração do Consumo (`src/App.jsx`)

No componente `App`, em vez de passar o texto "Search" através de uma prop explícita `label`, nós o passamos entre as tags de abertura e fechamento do componente `InputWithLabel`.

JavaScript

```
const App = () => {
  // ...

  return (
    <div>
      <h1>Minha aplicação</h1>

      {/* Uso da Composição: Passando elementos 'filhos' */}
      <InputWithLabel
        id="search"
        value={searchTerm}
        onInputChange={handleSearch}
      >
        {/* O conteúdo aqui dentro é passado como 'children' */}
        <strong>Search:</strong>
      </InputWithLabel>

      <hr />
      <List list={searchedStories} />
    </div>
  );
};
```

Note que removemos a prop `label` e inserimos um elemento HTML `<strong>` com o texto dentro do componente .

#### Refatoração da Definição (`src/App.jsx`)

Agora precisamos atualizar o `InputWithLabel` para renderizar o conteúdo que foi passado "dentro" dele. O React injeta esse conteúdo automaticamente na prop `children`.

JavaScript

```
const InputWithLabel = ({
  id,
  value,
  type = 'text',
  onInputChange,
  children, // A prop especial que contém tudo que está entre as tags
}) => (
  <>
    <label htmlFor={id}>{children}</label>
    &nbsp;
    <input
      id={id}
      type={type}
      value={value}
      onChange={onInputChange}
    />
  </>
);
```

**Benefícios Técnicos:**

1. **Flexibilidade:** Antes, a prop `label` só aceitava o que definíssemos (geralmente uma string). Agora, `children` pode ser qualquer nó renderizável do React: texto, elementos HTML (`<strong>`), outros componentes React, ou uma mistura deles. O componente `InputWithLabel` não precisa saber _o que_ está renderizando, apenas _onde_ renderizar .
    
2. **Semelhança com HTML:** A API do componente fica mais intuitiva, comportando-se como elementos nativos do DOM.
    

Isso conclui a transformação do componente de busca em um componente de entrada totalmente reutilizável e combinável.
