Nesta seção, implementamos a funcionalidade de **remover um item** da lista. Isso exige transformar a lista `stories` em um estado (para que possa ser modificada) e aprender a passar argumentos para handlers de eventos.

A lista estática `stories` agora se torna o valor inicial de um `useState`.

#### 2. Inline Handlers (Manipuladores em Linha)

O desafio técnico surge no componente `Item`: o botão de "Remover" precisa disparar `onRemoveItem`, mas precisa passar **qual** item deve ser removido.

Se fizéssemos `onClick={onRemoveItem(item)}`, a função seria executada imediatamente ao renderizar (causando erro). Precisamos passar uma função que, _quando chamada_, execute a remoção com o argumento correto.

**Solução: Arrow Function Inline**

JavaScript

```
const List = ({ list, onRemoveItem }) => (
  <ul>
    {list.map((item) => (
      <Item
        key={item.objectID}
        item={item}
        onRemoveItem={onRemoveItem}
      />
    ))}
  </ul>
);

const Item = ({ item, onRemoveItem }) => (
  <li>
    <span>...</span>
    {/* ... outros campos ... */}
    <span>
      {/* Inline Handler: Uma função que chama outra função com argumentos */}
      <button type="button" onClick={() => onRemoveItem(item)}>
        Dismiss
      </button>
    </span>
  </li>
);
```

**Análise Técnica:** A sintaxe `() => onRemoveItem(item)` cria uma nova função anônima a cada renderização do `Item`. Quando o usuário clica, essa função anônima é executada e, dentro dela, a função `onRemoveItem` é chamada com o argumento `item` que está disponível no escopo (closure).
