### **1. Meet the React Component**

Toda aplicação React é construída sobre **componentes**. O ponto de partida é o arquivo `src/App.jsx`.

Para simplificar o aprendizado e remover o código _boilerplate_ gerado automaticamente pelo Vite, o livro instrui a substituição do conteúdo de `src/App.jsx` por uma versão minimalista:

JavaScript

```
import * as React from 'react';

function App() {
  return (
    <div>
      <h1>Hello React</h1>
    </div>
  );
}

export default App;
```

**Conceitos Técnicos:**

- **Function Components:** O componente `App` é declarado como uma função JavaScript. Esta é a abordagem moderna do React, em contraste com as _Class Components_ (classes) utilizadas em versões mais antigas 1.
    
- **PascalCase:** O nome da função deve obrigatoriamente começar com letra maiúscula (ex: `App`, não `app`). O React diferencia componentes personalizados de tags HTML nativas (como `div`, `h1`) através dessa convenção 2.
    
- **Escopo de Variáveis:** Variáveis podem ser definidas dentro ou fora do componente.
    
    - _Dentro:_ A variável é redefinida a cada vez que a função do componente é executada (a cada renderização).
        
    - _Fora:_ Se a variável não depende de lógica interna (como _props_), ela pode ser definida fora para evitar redefinição constante 3.

### **6. React JSX (Páginas 21-25)**

O retorno da função do componente não é HTML puro, mas sim **JSX (JavaScript XML)**. O JSX é uma extensão de sintaxe que permite misturar HTML e JavaScript.

Para renderizar conteúdo dinâmico (variáveis JavaScript) dentro do JSX, utiliza-se a sintaxe de chaves `{}`.

JavaScript

```
const title = 'React';

function App() {
  return (
    <div>
      <h1>Hello {title}</h1>
    </div>
  );
}

export default App;
```

Atributos HTML no JSX:

Devido ao JSX ser transpilado para JavaScript, algumas palavras reservadas não podem ser usadas como atributos HTML nativos. O React adota o padrão camelCase 4:

- **`className`:** Substitui o atributo `class` do HTML (pois `class` é uma palavra reservada em JS para definição de classes).
    
- **`htmlFor`:** Substitui o atributo `for` usado em labels (pois `for` é usado em loops).
    

**Exemplo de implementação com atributos JSX:**

JavaScript

```
const title = 'React';

function App() {
  return (
    <div>
      <h1>Hello {title}</h1>
      <label htmlFor="search">Search: </label>
      <input id="search" type="text" />
    </div>
  );
}

export default App;
```

Interpolação de Dados:

O JSX permite a interpolação de qualquer expressão JavaScript dentro das chaves, não apenas strings primitivas. Isso inclui:

- Propriedades de objetos (ex: `{welcome.text}`).
    
- Execução de funções (ex: `{getTitle('React')}`).
    

Internamente, ferramentas como Babel/Vite transpilam esse JSX para métodos `React.createElement()`, que o navegador consegue interpretar 5.
