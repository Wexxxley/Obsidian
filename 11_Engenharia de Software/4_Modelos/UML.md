

---
UML é uma notação gráfica para modelagem de software. A linguagem define um conjunto de diagramas para documentar e ajudar no design de sistemas de software, particularmente sistemas orientados a objetos.

UML é o resultado de um esforço para unificar as notações gráficas que surgiram no final das décadas de 80. 

---
### **UML como Esboço**

Consiste em usar a UML para criar diagramas leves e informais de partes do sistema, principalmente para comunicação entre desenvolvedores. Não buscam ser completos, não geram código, e usam apenas um subconjunto dos diagramas UML .

- Usada em dois cenários principais:
	- **Engenharia Avante:** Desenvolvedores usam esboços para discutir e analisar alternativas de design _antes_ de codificar. 
		Ex: Esboçar classes e relacionamentos para implementar uma história de usuário .
	- **Engenharia Reversa:** Desenvolvedores usam esboços para explicar ou discutir uma funcionalidade _já implementada_. 
		Ex: Um dev experiente explicando código para um novato usando diagramas .    


Uma pesquisa com desenvolvedores mostrou que eles criam esboços com frequência para diversas finalidades (design de arquitetura, novas funcionalidades, explicar tarefas, analisar requisitos, entender código) . Muitos desses esboços são arquivados e cerca de metade contém elementos de UML, reforçando a relevância de aprender UML para comunicação e design informal .
