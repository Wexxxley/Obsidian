### **1. Matriz** 

Uma matriz é um conjunto de números reais dispostos em linhas e colunas.

![400](../attachments/Pasted%20image%2020260305143425.png)

#### **1.1 Matriz quadrada**
Uma matriz $A = [Aij] m*n$ é quadrada quando m=n.

![400](../attachments/Pasted%20image%2020260305144440.png)

#### **1.2 Matriz nula**
Uma matriz $A = [Aij] m*n$ é nula quando possui todas as entradas iguias a zero. 

![450](../attachments/Pasted%20image%2020260305145052.png)

#### **1.3 Matriz coluna**
Uma matriz $A = [Aij] m*n$ é dita coluna quando possui somente uma coluna.

![400](../attachments/Pasted%20image%2020260305145241.png)

#### **1.3 Matriz linha**
Uma matriz $A = [Aij] m*n$ é dita linha quando possui somente uma linha.

![400](../attachments/Pasted%20image%2020260305145343.png)

#### **1.4 Matriz diagonal**
Uma matriz $A = [Aij] m*n$ é dita diagonal quando A é quadrada e todas as entradas fora da diagonal principal são nulas.

As diagonais principais são as entradas da forma $a_{ij}$ com $i=j$.


![400](../attachments/Pasted%20image%2020260305145453.png)

#### **1.5 Matriz identidade**
Uma matriz $A = [Aij] m*n$ é dita identidade quando A é diagonal e todas as suas entradas da diagonal são 1.

![400](../attachments/Pasted%20image%2020260305150323.png)

#### **1.6 Matriz triangular superior**
Uma matriz $A = [Aij] m*n$ é dita triangular superior quando A é quadrada e todas as suas entradas abaixo da diagonal principal são 0.

![400](../attachments/Pasted%20image%2020260305150620.png)

#### **1.7 Matriz triangular inferior**
Uma matriz $A = [Aij] m*n$ é dita triangular inferior quando A é quadrada e todas as suas entradas acima da diagonal principal são 0.

![400](../attachments/Pasted%20image%2020260305150744.png)

#### **1.8 Matriz simétrica**
Uma matriz $A = [Aij] m*n$ é dita simétrica quando A é quadrada e suas entradas são simétricas em relação a diagonal principal.

![400](../attachments/Pasted%20image%2020260305150914.png)
